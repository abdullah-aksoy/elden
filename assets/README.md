# Demo medyası

Bu klasördeki videolar kök **README.md** içindeki `<video src="...">` adresleriyle gösterilir.

| Dosya | Kullanım |
|--------|-----------|
| `demo.mp4` | Birinci demo oynatıcısı |
| `demo-2.mp4` | İkinci demo oynatıcısı |

README’deki `<video src>` adresleri [`abdullah-aksoy/elden`](https://github.com/abdullah-aksoy/elden) deposunun `main` dalındaki `raw` yoluna işaret eder. Fork edip farklı bir depoda yayınlıyorsanız kök `README.md` içindeki URL’leri kendi kullanıcı ve depo adınıza göre güncelleyin. Büyük dosyalar için [Git LFS](https://git-lfs.com) veya YouTube gibi harici barındırma düşünebilirsiniz.
